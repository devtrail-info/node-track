# Task: node-hello

Write a small function that says hello.

## What to do

Open `index.js` and do two things:

1. Export a function `greet(name)`. It must return the text `Hello, <name>!`.
   For example, `greet('DevTrail')` returns `Hello, DevTrail!`.
2. When the file is run directly (`node tasks/node-hello/index.js`), print `greet('DevTrail')`.

## Check your work

```
npm run task -- node-hello
```

When all tests pass, commit and push your branch.
